Comment l’ajouter à Google Calendar / iPhone / Outlook ?
  • Google Calendar (ordinateur) : « Autres agendas » → « + » → « À partir de l’URL » → coller le lien copié.
  • iPhone / iPad : Réglages → Calendrier → Comptes → Ajouter un compte → Autre → Ajouter abonn. calendrier → coller le lien.
  • Outlook : Ajouter un calendrier → S’abonner à partir du web → coller le lien.
  • Android (selon l’application) : dans Google Calendar via un navigateur, utiliser la même procédure « À partir de l’URL ».
